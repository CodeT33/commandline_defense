# commandline_defense
A video game where you have to defend against enemies while you build a factory using a commandline.

---

## Color codes

`#00ffff` (aqua) path start
`#ff00ff` (pink) path end
`#ffff00` (yellow) path

`#ff0000` (red) restricted
`#00ff00` (green) placeable
`#0000ff` (blue) water
